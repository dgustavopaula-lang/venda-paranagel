# Paranagel — Landing Page Comercial

Ambiente local de desenvolvimento.

## Objetivo

Landing page comercial independente para apresentação do ativo Paranagel.

## Não publicar ainda

A página está configurada com:

`noindex,nofollow`

antes da publicação definitiva.

## Dados atuais

- Paranagel
- Paranaiguara — GO
- Valor comercial de referência: R$ 30.000.000
- Condições negociáveis
- Área comercial divulgada: aproximadamente 40.000 m²

## Contato

Configurar em:

`assets/js/app.js`

Variável:

`CONFIG.whatsapp`

Formato:

`55 + DDD + número`

Não adicionar sinais, espaços ou parênteses.
